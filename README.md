The Last Room: a program that draws one picture, with the Node standard library alone and no
network. A door stands open in an empty void; a small cat stands in the light coming out of it,
and the shadow it throws is far bigger than the cat.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
